## Regenerate the archive

```bash
python3 scripts/archive-asr-research.py
```

The collector scans surviving `/private/tmp` research roots, copies only small
reviewable text/source/evidence, captures dirty Git diffs, records original and
archived SHA-256, and writes a metadata inventory for every file. Absolute repo,
home, and temporary paths are redacted in copied text.

Use focused tests while iterating and the full check before landing. Explicitly
identify model-, accelerator-, network-, or large-fixture-dependent tests.

## Benchmark discipline

1. Freeze source/binary/model/vocabulary/fixture/PCM/settings/command hashes.
2. Use persistent workers, warmups, balanced order, and an A/A drift bracket.
3. Record p50/p95/p99/max, paired deltas, and bootstrap intervals.
4. Stop unrelated processes only by exact PID/path; never broad kill.
5. Record thermal/process state before and after.
6. Include load, precompute, memory, swap, disk, FD, and child-process costs.
7. Shut workers down by protocol and prove exit.
8. Preserve negative and hard-stop evidence.

## Archive integrity

- `ARCHIVED_CONTENT.json` binds originals to archived copies and redaction state.
- `TEMP_ROOT_INVENTORY.tsv` records every top-level research root.
- `ALL_TEMP_FILE_PATHS.tsv.gz` records every path under those roots.
- `source-patches/*/changes.patch` stores each dirty isolated checkout diff.

Git reconstructs source hypotheses and verifies artifacts against pinned hashes;
it is not a distribution channel for proprietary or huge generated bytes.
