# Замеры

## Что уже проверено

Первый сквозной прогон: скачивание модели, проверка контрольных сумм, загрузка
в память, распознавание. Всё локально, без единого обращения к сети после
загрузки модели.

**Железо**: Apple Silicon, macOS 26. **Движок**: Parakeet TDT 0.6B v3 через
FluidAudio 0.15.5, ревизия `aed02740059203c4a87495924f685de3722ae9ce`.

| Запись | Длительность | Распознавание | Быстрее реального времени | Пиковая память |
|---|---|---|---|---|
| Английская встреча | 30,7 с | 0,16 с | ~190× | 529 МБ |
| Смешанная RU/EN | 21,6 с | 0,12 с | **174×** | 101 МБ |
| Длинная запись | 3 мин | 0,40 с | 446× | 135 МБ |
| **Предельная** | **60 мин** | **18,3 с** | **197×** | **506 МБ** |

Часовая запись — заявленный предел одной диктовки — обрабатывается за семь
секунд и укладывается в полгигабайта. Запас есть даже на восьмигигабайтной
машине. Память растёт с длиной, потому что запись читается целиком: час звука
это 230 МБ отсчётов плюс сама модель.

Загрузка модели: **14,1 с** в первый раз после установки (компиляция под
нейромодуль), **0,14 с** при последующих запусках. Это подтверждает, что
прогрев нужно прятать в онбординг, а не в первую диктовку.

### Качество на смешанной речи

Главный сценарий продукта — русская речь с английскими терминами. Результат:

> Привет! Мы проверяем длинную запись русскоречии и английскими терминами.
> The product requirement is fast transcription with clear speaker labels.
> Нужно сохранить последнюю фразу и не потерять важное решение.

Английские фразы остались латиницей и не превратились в кириллицу — именно то,
на чём ломаются модели, специализированные под один язык. Ошибки есть
(«русскоречии» вместо «русской речи»), но переключение языков внутри записи
отрабатывает.

На английской записи название продукта распозналось как «why computer» вместо
«WaiComputer» — ожидаемо и лечится пользовательским словарём, ради которого он
и существует.

### Главная находка: термины внутри русской фразы

Фраза «Нужно сделать pull request и запустить deploy через Sentry»,
продиктованная по-русски, распозналась так:

> Нужно сделать **пул реквест** и запустить **деплой** через **центри**.

Это не сбой: внутри русской речи модель и должна писать кириллицей. Но для
разработчика результат непригоден. Отсюда готовый набор замен
(`StarterDictionary`) — он возвращает терминам обычный вид и предлагается
одной кнопкой. После него та же фраза выглядит как надо, что закреплено тестом.

Важное отличие от предыдущего абзаца: когда английская фраза идёт **отдельным
предложением**, латиница сохраняется сама. Проблема возникает только с
отдельными терминами внутри русской речи.

### Поведение на краях

| Случай | Что происходит |
|---|---|
| Тишина 3 секунды | Пустой результат. Ни одной выдуманной фразы |
| Запись короче 300 мс | Не распознаётся: человек передумал, ошибку не показываем |

Отсутствие галлюцинаций на тишине — заметное преимущество: модели семейства
Whisper в этом месте выдают заученные обрывки субтитров.

## Словарь терминов: догадки против измерения

Стартовый набор замен был написан по предположениям о том, как модель услышит
англицизмы в русской речи. Прогон пятнадцати фраз с этими же терминами показал,
что предположения почти не совпали с действительностью.

| Ожидали в словаре | Модель написала |
|---|---|
| пул реквест | пул рекв**и**ст |
| коммит | ком**е**т |
| код ревью | **кот** ревью |
| бранч | бран**ни**ч |
| гитхаб | гитх**е**б |
| постгрес | постгр**и**з |
| кубернетес | кубернет**и**с |
| хотфикс | **ход фикс** |
| роллбэк | роллб**у**к |
| продакшн | продакш |
| бэкенд / фронтенд | бэк**инг** / фронт**инг** |
| линтер | линт**и** |
| фича флаг | фич**и**-флаг |
| тайпскрипт | тайп-скрипт |

Из 32 проверенных терминов точно совпали 6.

Вторая находка важнее списка опечаток: **русский склоняет заимствованное слово,
а латинский термин не склоняется**. «После билда», «перед релизом», «на питоне»,
«без даунтайма» — замена по точному совпадению не срабатывала ни разу именно
там, где словарь и нужен. Теперь у кириллических замен допускается падежное
окончание из закрытого списка; латинских это не касается.

После обеих правок из 32 терминов узнаются 30. Оставшиеся два словарём не
берутся принципиально:

- **«в центре» → Sentry.** «Центр» — обычное русское слово, и замена ломала бы
  нормальную речь ради одного термина.
- **«редис» → «и дис».** Модель разорвала слово на союз и обрубок; собрать его
  обратно заменой нельзя.

Замер сделан на синтезе `say -v Milena`, поэтому конкретные написания на живом
голосе будут другими. Устойчива здесь не таблица, а вывод: **набор надо
собирать по выходу модели, а не по догадкам**, и склонения обязаны работать.

## Чего ещё нет

**Живой речи.** Все записи выше — синтез системного голоса macOS. Это не
доказательство для настоящего голоса: синтез ровный, без пауз, оговорок,
фонового шума и особенностей дикции.

Гейт фазы P0 требует записать 10–15 минут реальной речи с типичными терминами и
прогнать на ней три движка — Parakeet, Whisper large-v3-turbo и GigaAM, — плюс
облачный эталон для отсчёта. Критерий выбора: ошибки **на смешанной речи**, а не
на чистом русском. Если Parakeet проиграет больше трёх процентных пунктов,
движок меняется: адаптер изолирован ровно для этого.

**Скорости старта диктовки.** Метрика «от нажатия клавиши до первого отсчёта
звука» измеряется в фазе P1, когда появится захват с микрофона.

## Как повторить

```bash
swift build -c release --package-path Packages/LocalASR --product asr-bench
.build/release/asr-bench install          # ~483 МБ, один раз
.build/release/asr-bench bench запись.wav
```

Приватные записи держатся вне репозитория: каталог задаётся переменной
`WAI_EVAL_DIR`, в git попадают только короткие публичные фикстуры.
