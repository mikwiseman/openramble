# OpenRamble 0.41.0

# Your last takes, in the menu

- The OpenRamble menu now starts with your three newest dictations, as their own words. Click one to paste it into the app in front.
- Hold Option and the rows read Copy: click one to copy it. The separate Paste and Copy rows are gone.
- The takes are the ones from this session, and each leaves the menu when you delete it from the Library.

# A quieter panel while you speak

- While you dictate, the panel shows only a red dot, the sound meter and the time. The word "Listening" is gone.
- Hands-free dictation shows a red lock in the same place, at the same size. It no longer grows to show a key and the word "ends".
- A dictation that takes a moment longer says so in quiet gray text instead of bold black.
- The panel no longer shows Right Command when you chose another dictation key.

# Three shortcuts that work from any app

- ⌃⌘V pastes the last take and ⌃⌘R starts and stops a recording, as before.
- New: ⌃⇧⌘R opens the screen recording choices from any app, and Return starts. While you record, either shortcut stops the recording.
- ⌃⌘R is now delivered by macOS itself. The app in front no longer receives it as well, so it no longer runs your project in Xcode, and it works while a password field or a terminal protects typing.
- The menu prints only these three, in the shortcut column. Library, Settings and Quit show none, because theirs work only while an OpenRamble window is in front. ⌘R for the Library is gone; ⌘, and ⌘Q still work there.
- You can change or clear each shortcut in Settings → General.

Your voice and text still never leave your Mac.
