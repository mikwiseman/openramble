# OpenRamble 0.24.1

This update returns the Mac application to the native macOS implementation
shipped in OpenRamble 0.23.0.

## What changed

- The experimental Tauri-based Mac application introduced in 0.24.0 has been
  removed from the macOS release.
- The native Swift interface, menu bar controls, recorder, recognition path,
  history, dictionary, and Sparkle integration are restored.
- The bundle identifier and update-signing identity remain unchanged, so the
  update installs normally over both 0.23.0 and 0.24.0.

There are no new features in this release. Its purpose is to restore the last
native Mac application while keeping the existing update channel intact.
