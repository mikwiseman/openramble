# OpenRamble 0.21.1

Timing the last unmeasured step, and one link instead of two.

## The step nothing was watching

Short dictations were still taking several seconds, and the timings said the
recognition itself was fast. Every step had a number except one: the engine is
asked to make itself ready before each dictation, and that request was never
timed.

It is timed now. There was already a "prepare" figure in the record, but it
measured a different call on a different path — so it could read zero while
this one took seconds, which is precisely what was happening. A number that is
true about the wrong thing is worse than no number, and this is the second time
that has misled this investigation.

Nothing about dictation changes here. This release exists to make the next slow
one point at its own cause.
