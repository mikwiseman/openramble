# OpenRamble 0.22.0

A log you can send, and the measurement that finally covers the whole path.

## Logs you can share

A switch in About writes a plain text file you can open and send to someone.
It lives in your Logs folder, one file per day, and the button opens Finder
with today's file already selected.

Off by default, and while it is off nothing is written at all — no file
appears that you did not ask for. It records timings and reasons only. Nothing
you say is ever written to it.

## The measurement that was missing

Slow dictations have been hiding in a step nothing timed. Each release added
the measurement that seemed to be missing, and each time the slow part was the
next step along.

This release times the step between asking the speech model to work and it
starting: the handover itself. That is where the seconds were going. Every
timer before this one sat past that point and honestly reported zero.

The tool that reads these numbers was also rewritten. It used to identify
fields by counting them, so adding one field made it read a word as a duration
and report nonsense without complaint. It reads fields by name now, and a step
that was never measured says so instead of showing zero — the difference that
kept the real cause hidden.
