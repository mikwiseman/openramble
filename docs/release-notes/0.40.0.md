# OpenRamble 0.40.0

# Transcribe a file

- Drop an audio or video file on the Library window, or click the new import button in its toolbar. The file becomes a recording under its own name, you can play it at once, and its words appear as they are read.
- It reads M4A, MP3, WAV, AIFF, FLAC, Ogg and Opus voice notes, and the sound of MP4 and MOV videos.
- The language is recognized without asking. Only with the optional Hebrew model installed does an import ask one question: is the file in Hebrew.
- Dictation and recording keep working while a file is transcribed, and a file waits while you dictate.
- Your original file is only read. If you quit before a transcript is finished, it is finished the next time OpenRamble starts.

# Hebrew is easier to find

- Hebrew is now in Settings → Setup → More languages on every Mac. It used to appear only on a Mac with a Hebrew keyboard, so people who wanted it could not find it.
- A file in Hebrew needs only the Hebrew model: the import asks which language it is in. To dictate or record in Hebrew, switch your keyboard to Hebrew.
- If your Mac has no Hebrew keyboard, the Hebrew row says so after the download and opens Keyboard settings, where you can add one.
- First-run setup is unchanged: it offers Hebrew only on a Mac that has a Hebrew keyboard.
- The command-line tool can transcribe an audio file in Hebrew: `openramble lecture.m4a --hebrew`.

Your voice and text still never leave your Mac.
