# OpenRamble 0.40.0

# Hebrew is easier to find

- Hebrew is now in Settings → Setup → More languages on every Mac. It used to appear only on a Mac with a Hebrew keyboard, so people who wanted it could not find it.
- The row says how Hebrew is chosen: switch your keyboard to Hebrew to dictate or record in Hebrew.
- If your Mac has no Hebrew keyboard, the row says so after the download and opens Keyboard settings, where you can add one.
- First-run setup is unchanged: it offers Hebrew only on a Mac that has a Hebrew keyboard.
- The command-line tool can transcribe an audio file in Hebrew: `openramble lecture.m4a --hebrew`.

Your voice and text still never leave your Mac.
