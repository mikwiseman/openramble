# OpenRamble 0.10.0

Dictation behaves exactly as it did in 0.9.0. What changed is underneath: the
rules that turn what you said into the text that appears now come from a shared
core that Windows and Linux run too, so an improvement to them reaches every
platform instead of one.

Nothing about how you dictate changes. The hotkey, the dictionary, the history
and the recogniser are the same.

## Why this is safe to install

The previous implementation is still in the repository and is still the
specification. Both run over the same corpus on every build and must produce
identical text, identical trailing commands and identical protected spans — so
if they ever disagree, the build fails rather than your dictation quietly
reading differently.

## Also new

OpenRamble now exists for Windows and Linux. Recognition there runs on the
processor rather than the graphics card, so it is slower than on a Mac, and it
says so in its settings.
