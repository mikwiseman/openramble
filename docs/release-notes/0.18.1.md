# OpenRamble 0.18.1

The settings sidebar stops sliding under the window buttons.

Its list could scroll, and when it did the rows went up behind the red, yellow
and green buttons — "Dictionary" rendered directly underneath them. The last
release tried to fix this by giving the title bar a material to hide behind.
That was the wrong fix: it made the collision harder to see rather than
stopping it, and the rows kept moving.

There are five panes and they always fit, so the list has nothing to scroll.
It no longer can, which is a thing that cannot go wrong rather than a thing
that looks right.
