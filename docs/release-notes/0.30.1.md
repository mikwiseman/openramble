# OpenRamble 0.30.1

## Screen recording recovery and a calmer recording window

- Camera, microphone and Screen Recording permissions now have separate states and recovery actions.
- The screen flow is a compact preflight: choose a display, switch on the sources you need, and press Record. Bubble sizing appears only when the camera is enabled.
- Returning from System Settings refreshes the screen recorder in the same process. If macOS keeps a stale Screen Recording session, OpenRamble explains why and offers one explicit restart.
- A missing display is reported as a missing display, rather than as a generic permission failure.
- The recording panel and library toolbar use explicit icons, aligned controls and a compact layout that remains readable in both themes.
- The camera entitlement is checked in the release artifact, so enabling the bubble matches the permission the app actually requests.

All recordings remain local to this Mac. No cloud, YouTube or remote media path was added.
