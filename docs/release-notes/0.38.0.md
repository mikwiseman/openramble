# OpenRamble 0.38.0

# Dictation in Hebrew

- Hebrew is now an optional second download, about 740 MB. The main model does not hear Hebrew, so Hebrew has a model of its own.
- It is offered only on a Mac that has a Hebrew keyboard, in Settings → Setup and in first-run setup. To see the offer, add the Hebrew keyboard in System Settings → Keyboard → Input Sources.
- There is no language setting. A take is recognized in Hebrew while your keyboard is set to Hebrew, and as before on any other keyboard.
- A take or a recording keeps the language it started with. If you switch keyboards in the middle, the change applies when it ends.
- The Hebrew model writes Hebrew only, so switch the keyboard for an English sentence. Removing filler words and the spoken commands work in English and Russian, not in Hebrew.
- The model is Parakeet TDT 0.6B v3 Hebrew by Yakov Kolani, trained on ivrit.ai audio. Like the main model it runs on your Mac.

Your voice and text still never leave your Mac.
