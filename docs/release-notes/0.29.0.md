# OpenRamble 0.29.0

- One universal installer now runs on Apple Silicon and Intel Macs with macOS 14 or later.
- Intel support is experimental and uses the CPU for local recognition. Apple Silicon keeps Metal acceleration. Both use the same model, without a second download.
- Dictation, recordings and the bundled CLI use the matching architecture automatically.

The Intel executable is checked under Rosetta, including offline recognition from the signed installer. Performance and microphone capture still need testing on physical Intel Macs; Apple Silicon timings do not describe Intel performance.
