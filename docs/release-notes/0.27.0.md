# OpenRamble 0.27.0

Recordings start from the keyboard, the live window is quieter, and Share is gone.

# What changed

- Shift-Command-R starts and stops a recording from anywhere on the Mac. It is in Settings next to Copy last dictation, and it can be turned off. The Recordings window stays Command-0. The shortcut does not bring the window forward over a call; the menu-bar badge turning red is the confirmation. The first recording still explains System Audio Recording, and that sheet needs the window, so that one press opens it.
- The same keys still reach the app in front. A browser will reload from origin as well as start a recording. That is the cost of a default that is actually on; the copy shortcut stays off until you choose one, for the same reason.
- The live list row is a red dot and the elapsed time. The You and Others meters stay in the detail header, labelled, where they have room. They had been crushed into a dashed red line on the selected row.
- While you wait for the first paragraph, the transcript column says "Text appears after you pause" rather than a full-pane empty state. The engine still waits for a pause after about ten seconds of speech before it decodes — cutting sooner was measured to lose words.
- Share is removed from a finished recording. Copy the transcript, save it as Markdown, save the audio as an m4a, or show the file in Finder.

Recognition and transcription remain entirely local. Nothing is uploaded, and no other app is told you are recording.
