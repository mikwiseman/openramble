# OpenRamble 0.24.0

OpenRamble now uses the same Tauri application on macOS, Windows, and Linux.

## More predictable under load

- The microphone callback no longer allocates or waits for a lock. A fixed
  realtime ring moves audio to a dedicated collector, and stop drains every
  accepted frame before recognition begins.
- Recording, recognition, cancellation, and paste are serialized on one worker.
  Pressing the hotkey while recognition is busy is rejected instead of starting
  a recording later by surprise.
- The speech model warms while you speak and remains resident between takes.
- History writes use a bounded background lane and atomic index replacement, so
  a slow disk cannot delay pasted text or silently overwrite a damaged history.

## Universal Mac app

The Mac download now contains native Apple Silicon and Intel code and continues
to support macOS 14 and later. Intel recognition is compiled for a conservative
CPU baseline instead of assuming instructions available on the build machine.

The permanent bundle identifier, Accessibility permission identity, Sparkle
feed, and update signing key are unchanged. Existing installations update
normally.

## Interface and privacy

Settings use a responsive Liquid Glass design with native macOS vibrancy,
accessible controls, reduced-motion and reduced-transparency support, and no
stacked decorative glass.

On macOS, pasted or copied dictation is marked current-host-only, transient,
concealed, and auto-generated. It does not enter Universal Clipboard or
clipboard-manager history. Sparkle remains native and sends no system profile.
