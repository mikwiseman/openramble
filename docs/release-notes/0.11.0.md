# OpenRamble 0.11.0

The settings window now carries real material.

On macOS 26 that is Liquid Glass proper — the system material that samples and
refracts what is behind the window, not a fill drawn to look like it. On earlier
supported systems the same window uses the standard window material, which is
what Liquid Glass replaced and still the right answer there. Controls that float
on it follow the same rule.

Nothing about dictating changes. The hotkey, the dictionary, the history and the
recogniser are exactly as they were.

## Where glass is and is not

Glass is on the window and on the controls that float above it. It is not on the
settings groups themselves, because a settings pane is content — and stacking
glass on glass is the one thing the material's own guidance rules out. Depth
inside depth reads as clutter, not as craft.

## Accessibility

Reduce Transparency gives the window an opaque backing rather than a thinner
version of the effect. Increase Contrast adds a border to every glass surface.
Reduce Motion removes the press animation rather than shortening it.

## Underneath

The visual language — radii, spacing rhythm, stroke weights — now lives in one
file that generates both this app's constants and the Windows and Linux
interface's stylesheet. A change reaches both, and a hand edit to either fails
the build.
