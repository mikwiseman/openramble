# OpenRamble 0.18.0

Keep the dictations you want to keep.

## A star that means something

Every dictation in History now has a star. A starred one stays: it does not
count against your "keep last N" limit, and it is not deleted when newer
dictations push past it. Its audio stays with it.

A promise that a later dictation can break is not a promise, which is why the
limit counts only the unstarred ones rather than starring merely delaying the
inevitable.

## Your recordings, one click away

History has a button that opens the folder holding the audio. It opens with a
recording selected rather than dumping you in a directory to work out which
file is yours.

## Histories from older versions

They load unchanged, and nothing in them is starred until you say so.
