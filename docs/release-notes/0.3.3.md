# OpenRamble 0.3.3

- Uses the correct OpenRamble product name without spaces throughout the app, installer, repository, update feed, and website.
- Starts an explicitly requested model download on the current network, including hotspots and Low Data Mode, instead of remaining stuck at zero bytes.
- Keeps the exact model download failure visible with a Try Again action instead of immediately clearing it.
- Returns OpenRamble to the foreground after microphone access is granted so onboarding can continue in the same window.
