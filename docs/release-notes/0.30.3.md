# OpenRamble 0.30.3

## A quieter, more direct recording workflow

- Rename recordings directly in the list or detail header with double-click, Return, blur, and Escape behaving like native macOS editing.
- Open the selected recording in Finder from the toolbar, next to Copy Transcript.
- Keep one clear Record action. The microphone-only alternative is gone from the recording bar and first-run prompt.
- Drag the camera bubble in the live screen-recording preview and see the mirrored camera framing before recording.
- Keep row layout stable while editing so duration, dates, warnings, and multi-selection do not jump.

All recordings remain local to this Mac. No cloud, YouTube, or remote media path was added.
