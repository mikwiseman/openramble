# OpenRamble 0.25.2

A menu item is gone, and with it a copy of every dictation the app was keeping for it.

# What changed

- "Copy Last as Spoken" is removed. It copied what the speech model produced before the replacement dictionary and before punctuation and capitalisation, and it appeared only when that differed from the text you got. It was an escape hatch for a mangled word, but it could not help with the failure people actually hit: when a dictation comes back in the wrong language, the text underneath is in the wrong language too.
- Removing it also removes what it needed. The app was holding a verbatim copy of every dictation in memory so that button could offer it. Nothing keeps that copy now.
- "Copy Last Dictation" is unchanged and still returns the text that was inserted.

Recognition remains fully local and offline. No dictated text or audio is added to diagnostics.
