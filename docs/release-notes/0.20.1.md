# OpenRamble 0.20.1

Keep the logs that explain a slow dictation, and one version number
everywhere.

## Detailed logs, when you want them

A new switch in About keeps the engine's notes about loading, unloading and
warming up. They have always been written — but at a level macOS holds briefly
and throws away, so they existed only for whoever happened to be watching. The
moment you want them is after a slow dictation you did not expect, which is
exactly when they were already gone.

Off by default. It turns on nothing new: every step of every dictation is
timed and recorded either way, because a measurement that only exists when a
setting is on is a measurement missing from the report you actually need.

Nothing you say is ever written to a log. That has not changed and will not.

## The same version on every platform

The Windows and Linux packages were numbered separately and had drifted to
0.2.0 while macOS was at 0.20.0. They are one product; they now carry one
number.
