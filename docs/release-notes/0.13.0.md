# OpenRamble 0.13.0

Every setting can be put back, the copy shortcut is any key you press, and the
settings window stopped drawing a border under its own close button.

## The copy shortcut is yours to choose

Click the field next to "Copy last dictation" and press what you want. Escape
cancels, Delete removes it.

It is a chord — modifiers and a key — rather than one of four bare modifiers,
and that is the point rather than a limitation. The dictation key can only be
a modifier, because it is held down for a whole sentence and must type nothing
while you speak. Copying is a press, and a press bound to a bare Control would
fire every time you reached for Control on the way somewhere else. The function
row is the exception: F13 pressed alone types nothing, which is exactly why
people reach for it.

The shortcut is named by asking your keyboard layout, so one recorded on a
Latin layout still names a real key after you switch to Cyrillic — the same
reason a Mac menu shows ⌘Q while you type in Russian.

## Put any setting back

A small arrow appears beside a setting once you have changed it, and returns
just that one to its default. Not one button that resets everything: someone
who wants their dictation key back does not want their dictionary emptied, and
a button that does both is a button nobody dares press. The arrows also answer
"what did I change in here?" — they are only live where something differs.

## A space after each dictation

Optional, off by default. For dictating in runs, so the next phrase does not
arrive welded to the last word. It never appears after "new line", where a
space would just be an indent nobody asked for.

## Light, dark, or whatever your Mac is doing

A theme setting in About, alongside a button that opens the log folder — the
thing to attach to a bug report — and a link to the source, because an app
whose whole claim is that speech never leaves your machine should be readable
by anyone who doubts it.

## The window

The settings sidebar was held to a fixed size, so it drew as an inset panel
whose border ran directly under the close button. It reaches the window edge
again.
