# OpenRamble 0.15.0

More keys to dictate with, a settings window that sits properly, and
interrupted recordings filed where recordings belong.

## Seven keys instead of four

Left Command, Left Option and Right Control join the list. Left Command in
particular is where most people's thumb already rests, and it was missing for
no better reason than that the first four were enough to ship with.

"Any key" has an honest limit here. The dictation key is held down for as long
as you speak, so it can only be a key that types nothing while held — a letter
would fill your document with itself before you finished the sentence. Every
key that satisfies that is now offered.

Each of these is a specific physical key, not "some Command". macOS reports the
same flag whichever side you press, and telling them apart takes a separate bit
per key — one shared bit would mean holding the left Command started dictation
bound to the right one.

## The settings window

It was built on the Settings scene, whose chrome fights a sidebar on macOS 26:
the sidebar drew as an inset panel with its border passing under the close
button, and content scrolled up behind a title bar that left no room for it. It
is an ordinary window now, with the ordinary title bar every other Mac app has.

## Interrupted dictations are in History

They used to appear under the speech model, next to "Delete Model" — filed by
which part of the app produced them rather than by what they are. They are
recordings, so they are with the recordings now, saying plainly what happened:
a dictation that did not finish, whose audio was kept so nothing was lost.
