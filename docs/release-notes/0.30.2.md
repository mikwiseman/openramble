# OpenRamble 0.30.2

## A cleaner recordings library and a more reliable first frame

- The recordings list supports Shift/Command multi-selection, Move to Trash from the toolbar or context menu, Backspace/Delete, and double-click or Return to rename.
- Screen recordings show their first decoded frame immediately when opened instead of an empty black player while AVPlayer warms up.
- The screen setup panel now includes a live camera preview with simple Smaller/Larger controls. The self-view is mirrored like Zoom, and the bubble remains inside the frame.
- Completed recordings compact their transcription source to a stereo AAC archive after transcription finishes. The raw WAV remains in place if compaction cannot complete.
- H.264 screen files use predictable keyframes so the beginning and seeking stay responsive.

All recordings remain local to this Mac. No cloud, YouTube or remote media path was added.
