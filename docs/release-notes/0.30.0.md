# OpenRamble 0.30.0

- Record the selected Mac display locally from the same OpenRamble menu-bar app.
- Include microphone audio, Mac audio and an optional camera bubble in the recording.
- Move and resize the bubble while recording, pause and resume without adding a gap, then play or export the local MP4 beside its transcript.
- Keep screen recordings on this Mac. There is no media upload, cloud store, YouTube integration or share server.

Camera and Screen Recording permissions are requested only when their capture options are enabled.
