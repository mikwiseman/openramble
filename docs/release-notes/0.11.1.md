# OpenRamble 0.11.1

Settings is a sidebar now, and it fixes what 0.11.0 got wrong.

0.11.0 put a window material behind a tab strip that keeps its own opaque
background. The result was a hard dark band across the top of the window — a
half-applied effect, which reads as something broken rather than something
finished. That is gone.

The window uses a sidebar instead. On macOS a sidebar is genuinely translucent:
the system gives it real vibrancy that samples what is behind the window. It is
Apple's own material on the surface the system already treats as floating
chrome, rather than an effect drawn on top of one that refuses it.

Dictation is unchanged.
