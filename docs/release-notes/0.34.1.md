# OpenRamble 0.34.1

# The first word after a pause

- After your Mac has moved OpenRamble out of memory, the microphone now starts sooner when you press the key. OpenRamble keeps it set up between dictations without running it, so a press only has to start it. With memory full and every core busy, it started in 87 ms instead of 136 ms, and in at most 148 ms instead of 315 ms.
- The microphone still does not run between dictations.

Your voice and text still never leave your Mac.
