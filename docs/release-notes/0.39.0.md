# OpenRamble 0.39.0

# Dictation pastes while typing is protected

- A password field, or a terminal with Secure Keyboard Entry, protects typing. Some apps keep that protection on long after the password was typed, and until now OpenRamble refused to paste for as long as it lasted. It no longer refuses: the words are pasted as usual.
- ⌃⌘V now always pastes your newest dictation. It used to copy instead while typing was protected.
- If a paste still goes unread while typing is protected, the words wait on the panel as before, a tap of the dictation key copies them, and your own ⌘V pastes.

# Clearer error reports

- When a paste does not land, the journal on your Mac now records which kind of failure it was, and how long the app in front took to read each paste. It records no words. The journal leaves your Mac only if you choose Save Error Report in Settings → About and send the file yourself.

Your voice and text still never leave your Mac.
