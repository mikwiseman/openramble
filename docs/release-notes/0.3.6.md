# OpenRamble 0.3.6

## Clearer, quieter recording feedback

The floating recording panel now shows a live waveform from the microphone
signal instead of partial recognition text, a listening label, and elapsed
seconds. The separate live-preview recognition path and its setting are gone,
so OpenRamble no longer runs a second recognition stream while you speak.

The menu bar keeps the same OpenRamble mark in every state. A small blue dot
pulses while recording, stays steady while text is being prepared, and briefly
turns green only after a successful insertion.

The floating panel now disappears before insertion instead of showing a
redundant completion state over the destination application. Silence and error
messages remain visible and available to VoiceOver.
