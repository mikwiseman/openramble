# OpenRamble 0.28.0

Transcribe local audio from the command line with the Parakeet model you
already downloaded. Install `openramble` from Settings, then run
`openramble recording.m4a`. The app can stay closed and no connection is needed.

- Export plain text, JSON with word timestamps, SRT or VTT subtitles. Process
  multiple files with `--output-dir`; failed inputs do not stop the others,
  and existing output files are protected.
- Long recordings are read in small overlapping pieces, using one model and
  bounded audio buffers. Background CLI jobs pause for dictation and resume
  their unfinished work. Ctrl-C keeps completed output files.
- Recognition uses transcribe.cpp 0.2.3, which was faster and used less memory
  in our paired tests. Dictation still starts immediately with one decoder
  thread. The model weights are unchanged.
- Stereo imports include both channels, quiet passages are preserved, and
  resampling keeps the final audio samples.
- Cancelled recognition cannot insert an outdated result. Read-only CLI model
  checks no longer interfere with an installation in the app.

A shared `openramble-transcribe` skill is available in the repository for
Codex and Claude Code. It uses the installed CLI, keeps long transcripts in
files, and returns timestamps for the passages you need.
