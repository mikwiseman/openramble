# OpenRamble 0.21.2

The whole path from your voice to your text is now measured. No gaps.

Slow dictations kept hiding in a span nothing timed. Each release added the
measurement that seemed to be missing, and each time the slow part turned out
to be somewhere else — the timings said everything was fast while a dictation
took eight seconds.

The last unmeasured step was the wait for the recording to finish being written
and closed before anything can read it. It is timed now, and so is every other
step between the microphone stopping and the text arriving.

The profile also reports what is left over after all the named steps are
subtracted. While that figure is anything but zero, the breakdown is admittedly
incomplete and says so — rather than implying it has found the answer.

Nothing about dictation changes. This exists so the next slow one names its own
cause.
