# OpenRamble 0.4.0

## The menu bar icon now shows what's happening

The brand icon stays put; a small colored dot appears over its corner and
leaves when the work is done. Red means the microphone is capturing — never
earlier and never anything else. Blue means your speech is being transcribed
and inserted. Orange means something waits for you: setup isn't finished, or
a dictation still needs to be inserted. At rest there is no dot at all, and
the icon costs nothing — no animation, no timers.

## A menu you can read in five seconds

"Transcribe Saved Recording", "Delete Saved Recording", "Copy Saved Text" and
"Delete Saved Text" are gone, together with their confirmation dialogs. A
failed transcription is a rare technical event: it is reported the moment it
happens, the recording is kept quietly on this Mac for a few days and then
cleaned up by itself — no menu decisions required. Words that failed to
insert now join Recent Dictations immediately, so the whole recovery story is
one item: "Insert Last Dictation". "Copy Last Dictation Verbatim" became
"Copy Last as Spoken" and appears only when the spoken text actually differs
from what was inserted. The idle menu now teaches the gesture: "Ready — hold
⟨your key⟩ and speak".

## One color language everywhere

Red is reserved for the live microphone. Blue means working on speech. Green
means a good outcome. Orange means attention — and your work is preserved.
The dictation panel, the menu bar, onboarding and Settings all speak this
same language now; failures wear the orange attention triangle instead of a
destructive red cross, because nothing recoverable should look fatal.

## Recording feedback with a direction

The live waveform now draws every sample it receives and fades toward the
past, so the freshest sound is the brightest. While transcribing, the panel
shows a subtle system-animated waveform in blue — and a calm static one when
Reduce Motion is on.

## A first launch that gets out of your way

The setup step puts the model download first, so it runs while you grant the
two permissions below it. Permission descriptions say exactly what each
access is for — "Hears you only while you hold the dictation key" — and a
running trial dictation can no longer lock the whole window: Cancel Dictation
is right there. Headers are centered like macOS's own assistants, and the
window is one calm surface.

## Settings, the native way

Five tabs became four — General, Recognition, Dictionary, About — each a
grouped form with real footnotes where explanations belong. Updates moved
into About. Dictionary entries gained a visible delete button.
