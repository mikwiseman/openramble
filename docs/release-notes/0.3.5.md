# OpenRamble 0.3.5

## One OpenRamble mark while you dictate

OpenRamble now keeps its WAI mark in the menu bar throughout a dictation.
Previously it changed into a second microphone beside macOS's own orange
microphone privacy indicator, which made one app look like two microphone
tools.

Recording, transcription, setup, and recovered-work states remain available in
the menu, the floating status window, and VoiceOver without replacing the app's
identity.
