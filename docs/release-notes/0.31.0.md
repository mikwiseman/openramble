# OpenRamble 0.31.0

- Save an error report from Settings → About. One ZIP includes local technical events, app and macOS versions, and available crash details.
- A small local journal is enabled by default and limited to seven days and 5 MB. Existing logging opt-outs are respected; turning it off clears the journal.
- Reports exclude audio, transcripts, clipboard and document contents, personal paths and identifiers. Nothing is sent automatically.
- Release symbols are preserved with every release so crash addresses can be traced back to the exact build.
