# Жизненный цикл локальной модели

Safe beta использует один движок: Parakeet TDT 0.6B v3 через FluidAudio 0.15.5.
Модель не входит в приложение и скачивается только после нажатия кнопки
`Скачать модель — 483 МБ`.

## Готовность

Состояние `ready` существует только для ревизии из bundled manifest. Перед
запуском движка проверяются marker, точный список файлов, их размеры и metadata.
При установке, repair и обнаруженной mutation дополнительно сверяется SHA-256
каждого затронутого файла. Missing, extra, symlink и corrupt означают
`repairRequired`; библиотеке запрещено удалять или докачивать файлы самой.

## Обновление приложения

- Та же `modelID + revision + FluidAudio version`: существующая проверенная
  установка переиспользуется без сети.
- Новая несовместимая ревизия получает отдельную директорию и не подменяет
  рабочую модель. Интерфейс снова показывает явный объём 483 МБ; загрузка
  начинается только по отдельному нажатию пользователя.
- Promotion держит предыдущую установку в backup до записи marker новой. После
  прерывания `refreshState()` выбирает целиком старую либо целиком новую модель;
  частичная установка никогда не становится `ready`.
- Resume недокачанного файла в safe beta нет: Cancel и ошибка удаляют staging,
  следующий явный Retry начинает файл с начала.

Источники и redirect ограничены HTTPS allowlist для Hugging Face CDN и GitHub
mirror. Status, Content-Length, верхняя граница байтов и SHA-256 проверяются до
promotion.
