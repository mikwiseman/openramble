# Wai Dictation

Диктовка для Mac, которая работает целиком на вашем компьютере.

Нажали клавишу → сказали → отпустили → текст появился там, где стоял курсор. В любом приложении.

> Статус: в разработке. Первый релиз ещё не выпущен, готовых образов пока нет — собирается из исходников.

## Почему локально

Речь распознаётся моделью, которая лежит на вашем диске. Аудио никуда не отправляется — приложение работает в самолёте.

**Приложение выходит в сеть только по вашей команде:**

| Когда | Куда | Что узнаёт вторая сторона |
|---|---|---|
| Вы нажали «Скачать модель» | Hugging Face | IP-адрес, факт загрузки |
| Вы включили проверку обновлений | GitHub Pages — файл со списком версий | IP-адрес, версия приложения |
| Вы согласились установить обновление | GitHub Releases — сам образ | IP-адрес, факт загрузки |

Проверка обновлений по умолчанию **выключена**. Включается вручную: Настройки → Основное → Обновления. Пока она выключена, приложение само в сеть не ходит — ни при запуске, ни в фоне.

Больше ничего. Ни аккаунтов, ни аналитики, ни отчётов об ошибках, ни сторонних SDK.

Это не обещание, а проверка. Распознавание запускается в песочнице с полностью запрещённой сетью и обязано выдать текст:

```bash
./scripts/test-zero-network.sh
```

```
→ Собираю инструмент
Build of product 'asr-bench' complete! (0.21s)
→ Запускаю распознавание в песочнице без сети
  Модель загружена за 0.11 с

  === probe.wav ===
  Проверка работы без интернета.

Пройдено: речь распознана при полностью запрещённой сети.
```

Скрипту нужна уже скачанная модель — он проверяет то, что происходит после загрузки. Без неё скрипт скажет об этом и выйдет с кодом 69.

Отдельно на каждой сборке проверяется, что сетевые вызовы не появились там, где их быть не должно (`scripts/check-network-surface.sh`).

## Про клавиатуру — честно

Приложению нужно разрешение «Универсальный доступ» (Accessibility). Оно даёт две вещи: увидеть вашу горячую клавишу в любом приложении и вставить готовый текст.

Это значит, что системный монитор событий технически получает нажатия клавиш. Мы их **не логируем, не сохраняем и никуда не передаём** — код сравнивает событие с выбранной горячей клавишей и с Escape, всё остальное отбрасывает, не читая. Проверить можно здесь: [`GlobalHotkeyMonitor`](apps/macos/WaiDictation/System/GlobalHotkey.swift).

Разрешение «Мониторинг ввода» (Input Monitoring) приложению **не требуется**: код спрашивает систему только про `AXIsProcessTrusted()`.

## Что оказывается на диске

| Что | Где | Сколько живёт |
|---|---|---|
| Модель распознавания | `~/Library/Application Support/WaiDictation/Models` | Пока не удалите: Настройки → Модель |
| Запись текущей диктовки | `~/Library/Application Support/WaiDictation/Takes` | Удаляется сразу после распознавания |
| Текст, который не удалось вставить | `~/Library/Application Support/WaiDictation/Recovered` | Последние 20 файлов, не дольше недели |
| Настройки и словарь замен | `defaults` приложения | Пока не удалите приложение |

Записи и восстановленные тексты помечены как исключённые из резервных копий. Папка `Recovered` нужна, чтобы продиктованное не пропало, когда вставка не прошла (например, в поле пароля). Это обычные текстовые файлы: если диктуете чувствительное — чистите папку, приложение само хранит их до недели.

Чтобы убрать всё, достаточно удалить приложение и папку `~/Library/Application Support/WaiDictation`.

## Как пользоваться

- **Удерживайте** горячую клавишу, говорите, отпустите — текст вставится.
- **Двойное нажатие** включает режим без удержания: запись идёт до следующего нажатия.
- **Escape** отменяет диктовку, пока она идёт. В остальное время это обычная клавиша.
- Одна диктовка длится не больше часа; на пределе записанное распознаётся и вставляется.
- Текст вставляется через буфер обмена и ⌘V. Буфер пишется с ограничением текущим компьютером, поэтому диктовка не уходит в Universal Clipboard на другие устройства Apple ID.

## Требования

- macOS 14 или новее
- Mac на Apple Silicon. Приложение собирается universal и запустится на Intel, но распознавание там не работает — модель считается на нейромодуле
- 483,1 МБ на диске под модель (21 файл). На время установки нужно около 580 МБ свободного места: файлы сначала скачиваются во временную папку и только потом переезжают на место

Модель скачивается один раз с зафиксированной ревизии репозитория, и контрольная сумма каждого файла сверяется до установки. Половинчатая установка никогда не считается рабочей.

## Сборка из исходников

Нужен Xcode с тулчейном Swift 6 (проекты объявляют `swift-tools-version: 6.0`) и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`) — файл проекта в репозитории не хранится, он генерируется.

```bash
git clone https://github.com/mikwiseman/wai-dictation.git
cd wai-dictation

# Логика — быстрые тесты, модель не нужна
swift test --package-path Packages/DictationCore
swift test --package-path Packages/LocalASR

# Само приложение
cd apps/macos && xcodegen generate
xcodebuild -project WaiDictation.xcodeproj -scheme WaiDictation \
  -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build
```

Собранное приложение нужно запустить из Finder и выдать разрешения — микрофон и универсальный доступ. Дальше окно первого запуска доведёт до первой продиктованной фразы.

Пробный образ DMG (без подписи, запустится только на этой машине): `./scripts/build-dmg.sh`.
